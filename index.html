wizardgram

A compact toolkit for Telegram bots in Python, with examples for middleware, scenes, keyboards, webhooks, and file uploads.

Welcome to the spellbook

wizardgram keeps the framework simple: define handlers, attach middleware, manage scenes, and publish a bot that can poll or accept webhooks.

The docs on this site are built around the project’s own guidance and examples. Each page is meant to be quick to scan, while still giving you the exact snippets the package documents.

Coverage and confidence

The project tracks the current Bot API and documents what is verified. That helps you understand where the framework is covered and where a feature is inferred rather than fully exercised.

Verified and inferred

Bot API methods can be verified in the bundled method table, while some multipart upload behaviors are described as inferred when they have been exercised with mocked HTTP requests.
