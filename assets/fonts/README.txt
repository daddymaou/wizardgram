Download and place these font files in this folder before publishing the site: 

- Kalam-Regular.woff2
- Kalam-Bold.woff2
- SourceSerif4-Regular.woff2
- SourceSerif4-Bold.woff2
- JetBrainsMono-Regular.woff2

These files are referenced by the CSS in /assets/css/tokens.css. Until they are added, the site will fall back to readable system fonts without breaking layout or accessibility.
