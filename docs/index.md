# wizardgram

Async Telegram bot framework for Python.

wizardgram helps you build Telegram bots with async handlers, middleware,
regex-based routing, inline keyboards, and multi-step scenes. It supports
Python 3.10 and newer and keeps a clear record of which Bot API methods are
verified.

## Highlights

- Polling and webhook support
- Middleware chain for request processing
- Command, text, callback, and update handlers
- Fluent keyboard builders
- In-memory FSM scenes for multi-step flows
- Coverage checks for Bot API support
