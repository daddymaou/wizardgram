Middleware

Wrap updates before and after your handler chain.

Logging middleware

python
async def logging_middleware(ctx, next_): print(ctx.update_type) await next_() bot.use(logging_middleware)

This pattern runs logic around an update before it reaches the next handler. It is useful for logging, rate limiting, or other shared behavior.

When to use it

Middleware is a good fit when you want a single behavior to wrap many updates without repeating the same code in each handler.

Note: The project documents middleware as a central way to compose update processing, so the same mechanism can be used for logging and other shared behaviors.
