from wizardgram import status print(status("sendMessage").value)

The status helper reads from the bundled coverage table and prints the tracked verification value for a Bot API method.

What to expect

The project tracks the current Bot API and documents what is verified. That makes it easier to tell which methods are covered directly in the bundled status table and which areas are still inferred.

Verified

Core send methods, update polling, webhook methods, callback queries, and chat administration are all described as verified in the bundled table.
