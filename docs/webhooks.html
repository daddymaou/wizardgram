Webhooks

Accept Telegram updates from a webhook endpoint.

Webhook endpoint

python
async def telegram_webhook(request): return await bot.handle_webhook(request)

This is the project’s webhook pattern: pass the request object to the bot and let it handle the incoming Telegram update.

Webhook lifecycle

Set the URL once with await bot.set_webhook(...), remove it with await bot.delete_webhook(), and close the bot on shutdown with await bot.close().
