Install

Install the package and prepare your Telegram bot token.

Install the package

bash
pip install wizardgram

This is the basic install command for the framework. The package works with Python 3.10+.

Set your token

For a local run, set the environment variable before starting the bot process.

bash
export WIZARDGRAM_TOKEN="your-token-here"
powershell
$env:WIZARDGRAM_TOKEN="your-token-here"
Note

Set WIZARDGRAM_TOKEN before running your bot.
